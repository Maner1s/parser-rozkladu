# Парсер розкладу

Індивідуальний навчальний проєкт. **Студент:** Верхуша Назар Юрійович, ІПЗ-26-1.

## Мета
Перетворити офіційний розклад з таблиці Word (DOCX) на окремі структуровані записи CSV. Реальні витрати часу та потреби користувачів мають бути підтверджені, а не вигадані.

## Межі MVP
- DOCX одного перевіреного формату.
- Визначення дня, номера пари, I/II тижня, дисципліни, виду заняття та викладача.
- Обробка вертикально об'єднаних клітинок (vMerge).
- Виявлення неоднозначних записів без підстановки вигаданих даних.
- Експорт CSV після перевірки контракту листа «Пари».

Календар .ics, PDF та пряма інтеграція з Moodle не входять до MVP.
